# Analisador de Relatórios Pedagógicos com IA (EdTech)

## 📝 Descrição do Projeto
Este projeto consiste em um ecossistema automatizado e integrado em nuvem desenvolvido para otimizar a rotina de professores e especialistas em inclusão escolar. A solução captura dados brutos de observações diárias e utiliza inteligência artificial para estruturar relatórios pedagógicos formais, alinhados com as diretrizes da *BNCC* e das *NAPs de Florianópolis*.

---

## 🛠️ Arquitetura e Tecnologias Utilizadas
* *Interface de Entrada:* Google Forms (Coleta padronizada de requisitos dos alunos).
* *Modelagem de Dados:* Google Sheets (Armazenamento estruturado e histórico de registros).
* *Orquestração e Integração de Sistemas:* Make.com (Fluxo automatizado No-Code/Low-Code baseado em Webhooks e eventos).
* *Inteligência Artificial:* API do Google Gemini (Modelo Gemini Flash-Lite com engenharia de prompt avançada para análise comportamental e pedagógica).
* *Interface de Saída:* Google Docs (Geração automática de arquivos textuais organizados em pastas exclusivas no Google Drive).

---

## 💡 Competências Demonstradas
* *Engenharia de Prompt:* Criação de diretrizes restritas e contextualizadas para modelos de linguagem em ambientes educacionais.
* *Integração de APIs:* Conexão segura e gerenciamento de chaves de API globais corporativas.
* *Análise de Requisitos:* Mapeamento de regras de negócios e fluxos operacionais para automação de processos repetitivos.
